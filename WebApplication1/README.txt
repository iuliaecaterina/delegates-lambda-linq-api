Delegates, Lambda Expressions & LINQ – Demo Project

This project demonstrates the usage of Delegates, Lambda Expressions, and LINQ in C#, following specific requirements.
The goal is to show practical examples of how these concepts work and how they can be applied in
real-world scenarios, exposed through dedicated API controllers.

Requirements & Implementations

1. Delegates

✅ Used a delegate to call one method from another.
✅ Demonstrated execution of different delegate methods based on conditions.
✅ Implemented multicast delegates to call multiple methods sequentially.
✅ Both initialization types were used:
	->Named method
	->Lambda expression / anonymous method
2. Lambda Expressions

✅ Created examples for different lambda types:
	-> Without parameters
	-> With one parameter
	-> With two parameters
	-> With unused parameters
	-> With default parameter values
	-> With a tuple as parameter

✅ Implemented lambda expressions in both forms:
	-> Expression body
	-> Statement block

✅ Demonstrated usage of a lambda expression in an asynchronous context.

3. LINQ

✅ Created a class with at least 5 properties.

✅ Defined a static class containing a list of at least 5 objects of that type.

✅ Implemented queries that:
	-> Filter objects with where
	-> Select a single property into a list of strings
	-> Return the number of elements

✅ Demonstrated queries using both syntaxes:
	-> Query expression
	-> Method-based query

✅ Implemented a query that uses:
	-> Where
	-> Join
